# Velaphi

Website that helps users find out more about their Surnames by providing them with their clan names, history and well-known people who share that very surname.

Velaphi is a full stack web application that allows users to search for surnames and retrieve meaningful information associated with them. Built with HTML, CSS, and JavaScript on the frontend, Node.js and Express on the backend, and MySQL as the database, the application takes a surname entered by a user, queries a database, and dynamically renders a page populated with that surname's clan names, history, and well known people using EJS as the templating engine.
